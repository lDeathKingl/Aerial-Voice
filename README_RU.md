# Минимальный bridge-патч для Aerial 1.95

Этот патч не встраивает голосовой движок в Aerial. Он добавляет только передачу кнопки микрофона Xiaomi в отдельное приложение `app.orchard.tv.aerialvoice`.

## Что делает

- Обрабатывает только `KEY_F5` от устройства Bluetooth vendor `0x2717`, product `0x32B8`.
- Короткое нажатие открывает Aerial Voice и запускает один запрос.
- Удержание дольше 650 мс включает режим диалога.
- Все остальные кнопки и устройства ввода остаются в существующей логике Aerial.
- Не меняет `updateKeyFilter()` и не заставляет Aerial фильтровать клавиши чаще, чем это уже разрешает его собственная логика.

## Почему это безопаснее отдельной Accessibility-службы

Aerial 1.95 специально ограничивает фильтрацию клавиш на Xiaomi. В исходнике есть защита от проблем системного процесса при подключённой мыши/геймпаде. Отдельная Accessibility-служба, которая постоянно просит глобальную фильтрацию, обошла бы эту защиту и могла бы перехватывать весь поток клавиш.

Поэтому bridge использует уже существующий `HomeGuardService`. На Xiaomi Android 14 Aerial может не фильтровать клавиши, когда подключена мышь. В таком состоянии F5 не будет перехвачен — это намеренное ограничение ради стабильности телевизора. Не отключай защиту и не включай глобальную фильтрацию принудительно.

## Применение

В корне исходников `pengchujin/aerial-tv` на теге `v1.95`:

```bash
python3 patch/patch_aerial_voice.py .
```

Скрипт проверяет точные якоря и останавливается, если структура исходника отличается. Повторный запуск безопасен: патч идемпотентен.

После применения Aerial должен быть пересобран и подписан тем же ключом, которым подписана установленная Korobovo-сборка. Не устанавливай APK с другой подписью поверх существующего приложения: Android отклонит обновление. Не удаляй текущий Aerial ради проверки без предварительного резервного копирования его настроек.
