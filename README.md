# Aerial Voice 0.9.0 — Android TV voice assistant

Голосовой помощник для Xiaomi Android TV со встроенным русским **GigaAM v3**, онлайн-диалогом через **GigaChat**, озвучкой **RHVoice/Android TTS** и объединённым поиском фильмов в установленных приложениях.

## Функции
- **Поиск фильмов:** самостоятельный экран с карточками, постерами (если источник предоставляет), диагностикой провайдеров и прямыми Android-ссылками на результаты.
- **Zona:** поисковые `ContentProvider`, обнаруженные при статическом исследовании ATV Поиск 6.6. Требуется экспорт соответствующего провайдера самой Zona 3.0.79.
- **Кинотеатры:** поиск через найденные Android `SearchableInfo` — Zona, Кинопоиск, LazyMedia и поддерживающие стандарт приложения; для Lampa без ContentProvider предусмотрен запуск вручную.
- **Глобальный голос:** отдельные опциональные службы `VoiceInteractionService`, `RecognitionService`, `AccessibilityService`. Настраиваются на ПК отдельным скриптом **после** проверки основного приложения. Есть резервная копия и попытка отката.
- **Речь:** GigaAM v3 офлайн, подтверждение маршрута RC In, регулировка задержки автоотправки после тишины 0,9–2,5 секунды.
- **Громкость:** изменение `STREAM_MUSIC` с проверкой фактического уровня и сообщением об отказе прошивки.
- **Данные:** память, история, зашифрованный Authorization Key GigaChat, выбор TTS сохраняются при совместимой подписи APK и прежнем Android package ID.

## Скачать
Откройте GitHub Actions → `Build Aerial Voice Offline Bundle` и выберите **успешную сборку ветки `feature/unified-search-voice-0.9.0`**. В артефактах будет `aerial-voice-0.9.0-unified-search-offline` с двумя APK, офлайн-моделью, Windows-установщиком и скриптами глобального голосового вызова.

**Инструкция:** [tools/README_OFFLINE_RU.md](tools/README_OFFLINE_RU.md)

## Что ещё нужно проверить
CI компилирует Android-приложение, проверяет Java-тесты, PowerShell и SHA-256 скачанных компонентов. Доступность ContentProvider Zona 3.0.79, аппаратную кнопку F5 и громкость китайского Xiaomi можно подтвердить **только на конкретном телевизоре**.

Сохранение данных при обновлении требует одинакового package ID и совместимого ключа APK. Не удаляйте старую версию при ошибке подписи.
