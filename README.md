# Aerial Voice 0.8.1 — Android TV voice assistant

Русскоязычный голосовой помощник для Xiaomi Android TV, работающий отдельно от Aerial Korobovo. Проект рассчитан на сохранение настроек и истории при обновлении **того же package ID** с совместимой подписью.

## Основные функции
- Русская речь: **только локальный GigaAM v3 E2E CTC INT8**, 16 kHz mono. Vosk и его сетевой загрузчик удалены.
- Вход микрофона Xiaomi: `RC In` / `MIBT.VoiceControl`; подтверждаем фактический маршрут Android, не переключаемся на микрофон ТВ незаметно.
- Режим диалога с повторным прослушиванием после TTS, если аудиомаршрут прошивки позволяет; удержание F5 поддерживается HomeGuard-мостом в Aerial Korobovo.
- GigaChat с зашифрованным на ТВ Authorization Key, история диалогов, долговременная память.
- Русская озвучка установленным Android TTS (включая RHVoice, если он есть).
- Команды для приложений, громкости, паузы, HDMI и поиска фильмов.
- **Zona 3.0.79**: поддержка установленных `mobi.zona` и `ru.zona`, проверка `ACTION_SEARCH`, запасной запуск Zona без ложного сообщения, будто поиск завершён.
- Прямой голосовой запрос Zona: «Найди в Зоне фильм Дюна», «Поищи Интерстеллар в Zona». Также возможен поиск через Lampa и Кинопоиск, если они предоставляют Android-обработчик поиска.

## Скачать и установить
Выберите ветку `feature/gigaam-dialogue-zona-0.8.1` и GitHub Actions → **Build Aerial Voice Offline Bundle**. После успешного CI скачайте одноимённый ZIP-артефакт, содержащий APK, модель и Windows-установщик.

Полные инструкции: [tools/README_OFFLINE_RU.md](tools/README_OFFLINE_RU.md)

## Проверки
CI компилирует full/micTest APK и запускает JUnit, проверяет PowerShell-синтаксис и хэши runtime/model. **Физическую работу RC In, TTS и Zona 3.0.79 необходимо проверить на конкретном ТВ.** Встроенная диагностика показывает статус модели, микрофона, озвучки и Zona.

## Совместимость и безопасность
`app.orchard.tv.aerialvoice.mictest06` — пакет обновления, сохраняющий прежние данные только при совместимой подписи. Отдельный `app.orchard.tv.aerialvoice` имеет собственные данные. Нельзя автоматически перенести AES-ключ GigaChat между разными Android-приложениями.

Исторические скрипты из `patch/` относятся к предыдущим версиям и **не должны использоваться** для сборки 0.8.1.
