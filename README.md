# Aerial Voice 0.9.1 — Russian Android TV assistant

Русскоязычный голосовой помощник для Xiaomi Android TV: **офлайн GigaAM v3**, онлайн GigaChat, RHVoice/Android TTS, история и долговременная память.

## Главное в 0.9.1

- **Компактный голосовой интерфейс**: отдельное прозрачное окно поверх предыдущего приложения. Использует те же данные, TTS, GigaChat и команды, что и основной экран.
- **HomeGuard-совместимый маршрут F5**: старые команды запуска, адресованные `MainActivity`, перенаправляются в маленькое окно. Aerial Korobovo и его код не изменяются.
- **Необязательная системная кнопка F5**: отдельный Accessibility-мост, выключенный по умолчанию. Настройка с ПК сохраняет прежние параметры; системного ассистента не заменяет. Продвинутый режим замены ассистента включается отдельно.
- **Непрерывный диалог**: после завершения RHVoice запускается новая попытка записи, если RC In позволяет. При отсутствии звука система останавливается и сообщает о ограничении, а не бесконечно слушает тишину.
- **Поиск фильмов по Android ContentProvider** Zona, Кинопоиска, LazyMedia и обнаруженным видео-приложениям. Результаты показывают реальные постеры, год, рейтинг, жанр, если их отдал источник.
- **Голосовые продолжения**: «открой второй результат», «найди Дюну в Зоне и открой» (автопереход только если найден один результат).
- **Умный контекст**: снимок приложения/медиасессии и последняя открытая карточка фильма, без заявления, что воспроизведение точно идёт.
- **Громкость**: отчёт о фактически считанном уровне Android STREAM_MUSIC вместо ложного подтверждения HDMI/CEC.

## Скачать офлайн-архив

GitHub Actions → **Build Aerial Voice Offline Bundle** → выбрать успешную сборку ветки `feature/overlay-search-voice-0.9.1` → скачать артефакт `aerial-voice-0.9.1-overlay-search-offline`.

В ZIP уже входят оба APK, GigaAM v3, Windows-установщик и скрипты диагностики/отката. Для установки модели на ТВ сеть и VPN не требуются; GigaChat нуждается в интернете.

Полная пошаговая инструкция: [tools/README_OFFLINE_RU.md](tools/README_OFFLINE_RU.md).

## Реальные ограничения

Android не гарантирует перехват аппаратной кнопки китайского пульта в любом приложении. Компактное окно — прозрачная Activity, и отдельные плееры могут приостанавливать видео при потере фокуса. Доступность поискового ContentProvider именно установленной Zona 3.0.79 и переходов к карточкам должна проверяться на телевизоре. Установка новой версии через `adb install -r` сохраняет данные только при совместимом package ID и подписи.

**Актуальный исходный код:** ветка `feature/overlay-search-voice-0.9.1`. Сборка и тесты выполняются в GitHub Actions.
