# Aerial Voice 0.9.1 — компактный помощник, офлайн GigaAM и поиск фильмов

## Что входит

- Android APK для пакета `app.orchard.tv.aerialvoice.mictest06` (обновление ранее установленного Aerial Voice), дополнительный APK для `app.orchard.tv.aerialvoice`.
- Офлайн GigaAM v3 E2E CTC INT8 (модель и `tokens.txt`, SHA-256), без Vosk.
- GigaChat, история разговоров, долговременная память, настройки ИИ, RHVoice/Android TTS и голосовые команды.
- **Компактное полупрозрачное окно** поверх текущего приложения: позволяет спрашивать и отдавать команды, не переходя на полноэкранную страницу Aerial Voice. Это отдельная Activity, не системный вечно активный экран и не гарантирует, что кинотеатр не поставит видео на паузу.
- Прямой поиск через экспортированные Android ContentProvider Zona (в том числе для версии 3.0.79), Кинопоиска и других приложений. Запрашиваются только доступные на ТВ провайдеры. Утверждать, что Zona точно отдаёт результаты, пока не проверили на телевизоре, нельзя.
- Карточки поиска: названия, источники, доступные постеры, год, рейтинг и жанр **только если они действительно предоставлены источником**.
- Голосовые продолжения: «найди в Зоне Дюну», «открой второй результат», «найди Интерстеллар и открой» (последняя команда открывает карточку автоматически только при единственном результате).
- Настраиваемая задержка окончания фразы, работающая при доступном аудиоканале RC In.
- Управление громкостью с проверкой показаний Android; фактический HDMI/CEC-звук не может быть подтверждён без проверки на слух.

## Установка с ПК Windows 11

1. Открой GitHub Actions проекта → **Build Aerial Voice Offline Bundle** → успешный запуск ветки `feature/overlay-search-voice-0.9.1`.
2. Скачай артефакт `aerial-voice-0.9.1-overlay-search-offline`; распакуй **весь** архив, включая `offline-models`, в папку на компьютере.
3. ПК и ТВ должны видеть друг друга по ADB. Текущий адрес из предыдущих проверок — `192.168.2.89:5555`. Если IP изменился, укажи его параметром установщика.
4. Запусти **`INSTALL_OFFLINE.cmd`**. Установщик проверит модель, выполнит `adb install -r` без намеренного удаления старого приложения, скопирует модель и сверит хэш.
5. Когда предложит Authorization Key GigaChat, **просто нажми Enter**, если существующий ключ уже сохранён. Повторно вводить ключ без необходимости не требуется.
6. Если Android вернул `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, не удаляй старую версию. Подписи несовместимы; сначала сохрани данные.

**Отдельное подключение к VPN или скачивание русских моделей на телевизоре не требуется.** GigaChat по-прежнему нуждается в интернете. RHVoice должен быть установлен и настроен на ТВ.

## Как проверить

**Сначала не включай новый системный ассистент и Accessibility.**

1. Открой Aerial Voice и проверь, что прежняя история и ключ GigaChat на месте.
2. Нажми «Компактный голос поверх ТВ», произнеси вопрос; проверь, что появилось небольшое окно и работает RHVoice.
3. Открой Zona 3.0.79. Проверь работу кнопки микрофона, а затем голосовую команду «Найди в Зоне фильм Дюна».
4. Убедись, что открывается карточка найденного фильма. Если результатов нет, открой **Диагностика** и проверь список `Cinema search providers`.
5. После выдачи скажи «Открой первый результат». Номер соответствует последнему списку, сохранённому за последние 30 минут.
6. Проверь «Громкость 50 процентов» и сравни показания Android с реальным уровнем ТВ.
7. Проверь «Диалог: ВКЛ»: после ответа RHVoice приложение попытается снова слушать. Если китайская прошивка выключает микрофон пульта после отпускания кнопки, надёжный hands-free не гарантирован.

## Опциональная глобальная кнопка микрофона — с ПК

- `CHECK_GLOBAL_VOICE.cmd` — показывает текущего системного помощника и настройки Accessibility, **ничего не меняет**.
- `CONFIGURE_GLOBAL_VOICE.cmd` — **включает только дополнительный F5 Accessibility-мост**, сохраняя исходные настройки. Системного ассистента Xiaomi **не заменяет**. Если уже работает HomeGuard из Aerial Korobovo, **этот скрипт не запускай**, пока не убедимся, что он действительно нужен.
- `RESTORE_GLOBAL_VOICE.cmd` — восстанавливает сохранённые настройки из `aerial-voice-system-settings-backup.json`. **Не удаляй этот файл.**
- Продвинутый режим замены системного помощника предусмотрен отдельно через PowerShell: `-Mode Assistant` после `-Mode Setup`, но на китайской прошивке может конфликтовать с HomeGuard; по умолчанию он не используется.

Пример проверки с другим IP:
```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\configure-global-voice.ps1 -Mode Status -Tv "IP_ТВ:5555"
```

## Что эта версия не обещает

- Гарантированной доступности ContentProvider и deep-link на конкретной Zona 3.0.79 без проверки самого установленного APK.
- Истинной озвучки **поверх каждого** приложения при всех ограничениях Android: прозрачная Activity может временно приостанавливать видео.
- Управления физической громкостью Xiaomi за пределами поддерживаемого потока Android.
- Постоянного микрофона пульта без удерживания, если прошивка его отключает.
- Автоматического воспроизведения первого результата без явного и однозначного выбора пользователя.

CI подтверждает компиляцию, тесты и целостность моделей. Поведение пульта, Zona и HDMI/CEC проверяется на конкретном телевизоре.
