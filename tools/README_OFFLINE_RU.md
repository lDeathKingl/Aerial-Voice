# Aerial Voice 0.6.3 — установка с компьютера, офлайн-распознавание

Пакет включает **оба APK**, русские модели **GigaAM v3 E2E CTC INT8 + Vosk Small Russian**, их SHA-256, установщик Windows и диагностику. Установочный архив из GitHub Actions распаковывается **один раз** (без второго вложенного ZIP).

## Главное
- Старая версия **0.5.2** (`app.orchard.tv.aerialvoice.mictest`) не удаляется и остаётся доступной.
- Новая **0.6.3** использует отдельный пакет `app.orchard.tv.aerialvoice.mictest06`. Если ранее установлена 0.6.1/0.6.2 с таким же пакетом, обновление идёт через `adb install -r`; несовпадение подписи приводит к безопасной остановке, а не удалению.
- После скачивания этого ZIP на компьютер телевизору **не нужны интернет и VPN для установки моделей или распознавания**.
- Для ответов **GigaChat нужен интернет**, а для озвучки — русский TTS в Android.
- **Aerial Korobovo и HomeGuard не переустанавливаются**, их настройки остаются прежними.

## Установка
1. Скачайте ZIP, распакуйте его в отдельную папку Windows.
2. На компьютере должны быть Android Platform Tools (`adb.exe` доступен из PATH). Официальный источник: https://developer.android.com/tools/releases/platform-tools
3. Включите отладку ADB по сети на Xiaomi TV. Компьютер и ТВ должны быть в одной сети.
4. Запустите `INSTALL_OFFLINE.cmd` (или `offline-install.ps1 -Tv "IP:5555"` если адрес другой). IP по умолчанию — `192.168.2.89:5555`.
5. Скрипт проверит модели на компьютере, наличие свободного места на ТВ, установит APK **без удаления данных**, выдаст разрешение микрофона (если доступно), скопирует обе модели и повторно проверит контрольные суммы на ТВ.
6. При наличии старой 0.5.2 скрипт **попробует** перенести историю последних 30 сообщений. Если Android не разрешит `run-as`, старая история останется в 0.5.2; ошибка не остановит установку. Перенос старого зашифрованного API-ключа невозможен.
7. На компьютере появится **скрытый запрос Authorization Key GigaChat**. Вставьте ключ и нажмите Enter. Если его нет — нажмите Enter и настройте позже.
8. Ключ передаётся временным файлом через ADB, приложение проверяет шифрование и обратное чтение в Android Keystore, создаёт короткое подтверждение `ok`, а установщик удаляет временные файлы.
9. После запуска приложения откройте **«Распознавание»** и выберите «Авто», «Только GigaAM v3» или «Только Vosk». В режиме «Авто» GigaAM выполняет основное распознавание, а Vosk используется при сбое.

## Диагностика после установки
- Сначала откройте **«Проверить микрофон пульта · RC In»**. Удерживайте микрофон пульта и смотрите уровень сигнала.
- Откройте **«Диагностика»**: там показаны установленные модели, фактический последний движок, время обработки, аудиомаршрут, свободное место, ошибки и состояние TTS.
- Если запись не работает, запустите на ПК:
  ```powershell
  powershell -NoProfile -ExecutionPolicy Bypass -File .\diagnose-offline.ps1 -Tv "192.168.2.89:5555"
  ```
  Скрипт создаст текстовый файл диагностики рядом с собой. **Просмотрите отчёт на наличие личных данных перед отправкой**.

## Что входит
- `aerial-voice-mictest06-debug.apk` — устанавливается скриптом, отдельный пакет
- `aerial-voice-full-debug.apk` — альтернативный вариант, скрипт его не устанавливает
- `offline-models/vosk/vosk-model-small-ru-0.22.zip` — Vosk
- `offline-models/gigaam-v3/model.int8.onnx` и `tokens.txt` — GigaAM
- `offline-models/manifest.json` — SHA-256 и размер
- `INSTALL_OFFLINE.cmd`, `offline-install.ps1`, `diagnose-offline.ps1` и `prepare-offline-models.ps1`

## Ограничения
- Запуск на GitHub Actions проверяет **компиляцию, тесты, PowerShell-синтаксис, состав и контрольные суммы пакета**, но **не подтверждает качество работы микрофона на конкретном Xiaomi TV**.
- На некоторых прошивках аудиовход RC In не выдаёт данные сторонним приложениям. Смена распознавателя не устраняет такое аппаратно-программное ограничение.
- Офлайн-модель INT8 на слабом ТВ может работать медленно. Переключитесь на Vosk, если время распознавания слишком велико.
- Ввод GigaChat-ключа через ПК создаёт кратковременные незашифрованные файлы. Установщик и приложение пытаются их удалить, но флеш-память не гарантирует физического стирания. Используйте доверенный ПК и безопасное ADB-подключение.
- Если установка остановилась из-за подписи, не удаляйте старое приложение: сохраните лог и проверьте debug-ключ.
