# Aerial Voice 0.6.2 — полноценный офлайн-комплект распознавания

Этот ZIP содержит два APK Aerial Voice, обе русские модели распознавания, проверочный manifest.json и установщик через ADB.

## Важное
- **Не удаляйте Aerial Voice 0.6.1** и другие приложения на телевизоре.
- Установщик по умолчанию обновляет отдельное приложение `app.orchard.tv.aerialvoice.mictest06`. Оно использует прежнюю debug-подпись. Если подпись не совпала, установка остановится без удаления данных.
- `Aerial Korobovo` и `HomeGuard` не обновляются и не изменяются.
- Интернет и VPN **не нужны телевизору** для установки или распознавания. Обе модели уже лежат в ZIP.
- Интернет всё ещё нужен для запросов к GigaChat. Android TTS зависит от установленного голосового движка.

## Установка с Windows
1. Распакуйте ZIP целиком в обычную папку на компьютере (не запускайте установщик из ZIP).
2. Подключите компьютер к сети телевизора. На телевизоре включите отладку ADB по сети.
3. Установите Android Platform Tools, чтобы команда `adb` была доступна из терминала.
4. Дважды нажмите `INSTALL_OFFLINE.cmd`. Адрес по умолчанию — `192.168.2.89:5555`.
5. Если адрес другой, запустите:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\offline-install.ps1 -Tv "ВАШ_IP:5555"
   ```
6. Установщик проверит три файла моделей на ПК, обновит APK без удаления данных, скопирует модели на телевизор и сверит SHA-256 после передачи.
7. После импорта Vosk при первом запуске приложение будет использовать GigaAM v3 E2E CTC INT8 (основной), Vosk (резервный). Процесс первичной распаковки Vosk может занимать время.

## Что внутри
- `aerial-voice-mictest06-debug.apk` — обновление существующего Aerial Voice с отдельным пакетом
- `aerial-voice-full-debug.apk` — полный variant (не устанавливается скриптом, чтобы не затронуть другие пакеты)
- `offline-models/gigaam-v3/model.int8.onnx` — GigaAM v3 E2E CTC INT8
- `offline-models/gigaam-v3/tokens.txt` — словарь GigaAM
- `offline-models/vosk/vosk-model-small-ru-0.22.zip` — русская модель Vosk
- `offline-models/manifest.json` — SHA-256/размеры
- `offline-install.ps1` и `INSTALL_OFFLINE.cmd` — установка

## Ограничения
Наличие работающего маршрута `RC In / MIBT.VoiceControl` на Xiaomi TV проверить на GitHub Actions нельзя. Компиляция подтверждает корректность кода, но не доказывает, что микрофон пульта выдаёт PCM в конкретной прошивке. GigaAM проверяется на телевизоре; при ошибке используется Vosk.

Если установка остановилась из-за несовпадения подписи, **не удаляйте установленный пакет**, а передайте лог/скриншот. Установка не обходит подпись и не стирает данные.

Установка полностью автономна для распознавания при условии, что ZIP уже скачан на компьютер.
