# Aerial Voice 0.9.0 — офлайн GigaAM, поиск фильмов и глобальный голос

**Исходная версия:** Aerial Voice 0.8.1. Обновление не требует удаления приложения и не должно очищать его данные, если пакет Android и подпись APK совпадают.

## 1. Установка с ПК, без скачиваний на телевизоре

1. Открой GitHub Actions → `Build Aerial Voice Offline Bundle` → успешный запуск **для ветки `feature/unified-search-voice-0.9.0`**.
2. Скачай артефакт **`aerial-voice-0.9.0-unified-search-offline`**. Полностью распакуй архив в отдельную папку Windows, не запускай файлы внутри ZIP.
3. Убедись, что компьютер соединён с телевизором по ADB. В распакованной папке запусти **`INSTALL_OFFLINE.cmd`**.
4. Установщик использует адрес `192.168.2.89:5555` по умолчанию, сверяет локальную модель GigaAM, обновляет APK с `adb install -r` и копирует модель в каталог приложения. **Vosk не используется; скачивать модели или включать VPN на ТВ не нужно.**
5. Не удаляй установленную 0.8.1 перед установкой. Если появится `INSTALL_FAILED_UPDATE_INCOMPATIBLE` — остановись: APK подписан другим ключом. Сначала сохрани данные, не делай `adb uninstall`.

По умолчанию используется `app.orchard.tv.aerialvoice.mictest06` — пакет, который ранее устанавливался на телевизор. В архиве также есть `aerial-voice-full-debug.apk` для отдельного пакета `app.orchard.tv.aerialvoice`, у него **собственные данные и ключи**.

## 2. Что добавлено

- **Новый экран «ПОИСК ФИЛЬМОВ»**: ручной ввод или голосовые запросы, результаты по установленным кинотеатрам, источники, доступные постеры и переход к карточке.
- **Поиск через Android ContentProvider**: динамическое обнаружение `SearchableInfo` и проверенные по структуре Android-интерфейсы Zona (`mobi.zona.TvSearchProvider`, `ru.zona.app.android.tv.search`, `free.zona.TvSearchProvider`), Кинопоиска, LazyMedia. Нет обращения к скрытым серверам ATV Поиск.
- **Zona имеет приоритет** в общей выдаче. Установка Zona 3.0.79 НЕ гарантирует, что ContentProvider экспортирован на твоей прошивке; проверка выполняется на ТВ.
- **Голосовое открытие поиска**: «Найди в Зоне фильм Дюна», «Поищи Интерстеллар в Zona», «Найди сериал Тьма». Ответ не обещает успешную выдачу, пока она не появилась.
- **Громкость**: ассистент проверяет, изменился ли уровень STREAM_MUSIC, и сообщает точный результат вместо ложного подтверждения. Управление аппаратной громкостью Xiaomi/HDMI-CEC может быть недоступно Android.
- **Диалог**: нажатие экранной кнопки начинает запись с автоотправкой после тишины. При нажатии микрофона пульта по-прежнему важна доступность маршрута `RC In`; удержание кнопки может быть необходимо на китайском Xiaomi.
- **Опциональный системный ассистент и F5-мост**: Android `VoiceInteractionService`, `RecognitionService`, `AccessibilityService`; не включаются автоматически. HomeGuard не удаляется и не изменяется.
- Сохранены GigaAM v3, GigaChat, RHVoice/Android TTS, память, история, настройки и запуск приложений.

## 3. Дополнительная настройка глобальной кнопки через ПК

**Не запускай перед проверкой обычного поиска и распознавания.** Сначала проверь, что Aerial Voice стартует, распознаёт голос и выдаёт результаты Zona.

- `CHECK_GLOBAL_VOICE.cmd` — показать текущее назначение системного помощника. Не меняет настройки.
- `CONFIGURE_GLOBAL_VOICE.cmd` — установить Aerial Voice как помощника и включить Accessibility-мост для F5. **Может заменить системного голосового ассистента и конфликтовать с HomeGuard.** Запускай только если хочешь его заменить. Скрипт сохраняет оригинальные системные настройки рядом с собой в `aerial-voice-system-settings-backup.json`.
- `RESTORE_GLOBAL_VOICE.cmd` — восстановить сохранённые системные настройки и попытаться восстановить роль прежнего помощника. **Не удаляй файл резервной копии.**

Если IP изменился, открой PowerShell в папке и укажи адрес вручную:
```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\configure-global-voice.ps1 -Mode Status -Tv "НОВЫЙ_IP:5555"
```
Аналогично `-Mode Setup` и `-Mode Restore`. Нельзя гарантировать, что китайская прошивка пропустит аппаратную F5 или разрешит изменение защищённых параметров даже через ADB. В настройках Android можно вручную включить Accessibility-службу **«Aerial Voice — глобальная кнопка микрофона»**.

## 4. Проверка на телевизоре

1. Открой Aerial Voice → **Диагностика**: GigaAM, RC In, RHVoice, реальные **Cinema search providers**, Zona, Volume.
2. Нажми кнопку **ПОИСК ФИЛЬМОВ** и введи «Дюна». Должны появиться результаты от доступных провайдеров или честная диагностика отсутствия доступа.
3. Скажи «Найди в Зоне фильм Дюна», попробуй открыть найденную карточку кнопкой OK. Если провайдер отдаёт результаты без ссылки, приложение предложит просто открыть кинотеатр.
4. Скажи «Громкость 50 процентов» и «Сделай громче». Проверь фактический звук и ответ — система не должна утверждать, что громкость изменилась, если уровень STREAM_MUSIC остался прежним.
5. Нажми **Начать разговор**, произнеси вопрос, сделай паузу ~1,5 секунды — система должна отправить фразу автоматически, если RC In всё ещё активен.
6. Если всё работает, при желании проверь глобальную кнопку через отдельные скрипты выше.

## Ограничения

- Сборка и JUnit-тесты проходят в GitHub Actions. **Проверка физической F5, выдачи Zona 3.0.79, перехода к фильму и HDMI-CEC возможна только на телевизоре.**
- Стандартный Android ContentProvider может не отдавать рейтинги и изображения; в таком случае карточка будет текстовой.
- На некоторых устройствах микрофон пульта активен исключительно при удержании кнопки. Приложение не может обойти аппаратное ограничение без отдельного поддерживаемого маршрута.
- Для GigaChat нужен интернет. Распознавание GigaAM и модель устанавливаются офлайн. Русскую озвучку обеспечивает установленный в Android RHVoice или другой TTS.
- Системные настройки и разрешения не меняются обычным `INSTALL_OFFLINE.cmd`, только отдельным `CONFIGURE_GLOBAL_VOICE.cmd`.
