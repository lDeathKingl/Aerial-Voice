# Aerial Voice 0.8.1 — офлайн GigaAM v3, диалог и Zona 3.0.79

## Что входит

- Два APK с одинаковыми функциями помощника: `aerial-voice-mictest06-debug.apk` (обновление пакета `app.orchard.tv.aerialvoice.mictest06`, используется установщиком по умолчанию) и `aerial-voice-full-debug.apk` (другой пакет `app.orchard.tv.aerialvoice`).
- Русская модель **GigaAM v3 E2E CTC INT8**, `model.int8.onnx` и `tokens.txt`, с проверкой SHA-256. **Vosk удалён из приложения и не устанавливается**.
- `offline-models/manifest.json`, `INSTALL_OFFLINE.cmd`, `offline-install.ps1`, `diagnose-offline.ps1`, `prepare-offline-models.ps1`.
- История, долговременная память, настройки GigaChat, русская озвучка TTS, голосовые команды Android TV, переключение HDMI и поиск фильма через совместимые Android-интенты.

**Важно:** ZIP уже содержит модель, и при установке на телевизор **не нужно скачивать модели, использовать VPN или интернет**. Для самого GigaChat требуется соединение с интернетом. Озвучка использует установленный TTS-движок Android; без русского TTS текстовые ответы всё равно будут отображаться.

## Установка с Windows 11

1. Откройте GitHub Actions → **Build Aerial Voice Offline Bundle** для ветки `feature/gigaam-dialogue-zona-0.8.1` и скачайте артефакт `aerial-voice-0.8.1-gigaam-zona-offline`, если запуск завершился успешно.
2. **Распакуйте ZIP полностью**, включая папку `offline-models`. Не запускайте установщик внутри ZIP.
3. Установите [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools), чтобы `adb` работал из терминала Windows. Включите ADB по сети на телевизоре, подключите его и ПК к одной сети.
4. Запустите `INSTALL_OFFLINE.cmd`. По умолчанию используется IP `192.168.2.89:5555`. Если он изменился, запустите PowerShell из распакованной папки: `powershell -ExecutionPolicy Bypass -File .\offline-install.ps1 -Tv "НОВЫЙ_IP:5555"`.
5. Установщик проверит оба файла модели на ПК, подключится к телевизору, выполнит `adb install -r` **без удаления старой версии**, выдаст доступ к микрофону (если Android разрешает), скопирует модель и сверит SHA-256 на ТВ.
6. Если ключ GigaChat не удалось перенести в новый пакет, введите его повторно в настройках ИИ. Зашифрованный ключ не копируется между пакетами автоматически.

Если установщик сообщает `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, **не удаляйте старое приложение**. Подпись APK отличается; требуется разобраться с ключом подписи и резервной копией.

## Микрофон пульта

- Откройте **Тест микрофона**, проверьте наличие `RC In` / `MIBT.VoiceControl`.
- Приложение использует только маршрут микрофона пульта, который Android реально подтвердил. Оно не подменяет его молча встроенным микрофоном ТВ.
- Удерживайте F5/микрофон во время произнесения фразы, затем отпускайте. Долгое удержание может включать режим диалога при работающем HomeGuard-мосте Aerial Korobovo.
- В меню **Распознавание** можно выбрать только источник Android AudioRecord: `VOICE_RECOGNITION` (по умолчанию) или `MIC`. Движок всегда GigaAM v3.
- После озвученного ответа в режиме диалога помощник попробует начать слушать снова. Если прошивка отдаёт звук пульта лишь при удержании кнопки, полностью свободный диалог аппаратно не гарантирован.

## Голосовой поиск Zona 3.0.79

Проверьте **Диагностика → Zona**: ожидается `mobi.zona / 3.0.79` (у старых установок может быть `ru.zona`).

Примеры:
- «Найди в Зоне фильм Дюна»
- «Поищи Интерстеллар в Zona»
- «Найди сериал Тьма»

Если Zona экспортирует обработчик Android `ACTION_SEARCH`, Aerial Voice передаст название. Если нет — откроет Zona и **не будет утверждать**, что фильм уже найден. В таком случае откройте вкладку «Поиск» вручную; внешний API поиска конкретной сборки Zona 3.0.79 без проверки APK и телевизора не подтверждён.

## Диагностика

Запустите `diagnose-offline.ps1` или откройте **Диагностика** в Aerial Voice. Отчёт покажет установленную Zona, файлы GigaAM, маршрут RC In, TTS и ошибки. Не публикуйте API-ключи и токены.

## Ограничения

- `GigaAM` может распознавать заметно медленнее, чем старый Vosk, на слабом процессоре телевизора.
- Сохранение истории и настроек через `adb install -r` работает только при том же Android package ID и совместимой подписи.
- Сторонние приложения могут игнорировать `ACTION_SEARCH` даже при наличии обработчика: фактический переход к результатам Zona надо проверить на ТВ.
- **Aerial Korobovo и HomeGuard не переустанавливаются** данным ZIP и не должны затрагиваться.
